# Bilateral relations engine (prototype, Python)

Scores the relationship between any two countries on a scale of **−200 … +200** (`R = S_struct + S_dyn`) from real data: Wikidata (embassies, memberships, treaties, claims), World Bank WITS (trade), UN DESA (migrant stock), and dated facts extracted from news/Wikipedia by LLM agents, classified by two independent models plus a judge, with time decay and standing measures. The full specification is in [`docs/modelo_puntuacion.md`](docs/modelo_puntuacion.md); the calibration and validation record is in [`docs/calibracion.md`](docs/calibracion.md) (both in Spanish).

> **Status:** Python engine. The app reads its export, `lib/data/bilateral-relations/relations.json`, through `GET /api/relations/[code]`: in the monitor's relations mode the globe and the 2D map colour every country by the band of R with the selected one, and the sidebar shows the best and worst partners with their embassies and states. No Python runs inside the app.

## Layout
| Folder | Contents |
|---|---|
| `model/` | The model: `scoring.py` (catalog, `score()`), `structure.py` (states from data and derived from facts), `embassy.py` (embassy state per side: present / absent / unknown), `measures.py` (standing measures), `verify_states.py` (re-verification of old states), `classify_score2.py` (two-model pipeline, CLI), `flow.py` + `providers.py` (LLM/search clients with key rotation), `migration.py`, `gen_doc.py` (regenerates the spec). Plus the caches that make runs reproducible offline (`*_cache.json`) and the fact lists of the 5 demo pairs (`v6_*.json`). `structure_v4.py` (pre-measures) and `structure_v6.py` (pre-embassy-state, 36-month cut) are kept only as the "before" baselines of the held-out comparisons. |
| `calibration/` | Anchors and hand labels frozen by hash (`*.sha256`), extracted facts (`facts_*.json`), source texts, the calibration/validation scripts, protocols and results. |
| `docs/` | `modelo_puntuacion.md` (generated by `model/gen_doc.py`) and `calibracion.md`. |
| `results/` | Output of the 5 demo pairs (two runs each). |

## World run (all 197 states, 19,306 pairs)
`world/` scores every pair of the 193 UN members plus the Holy See, Palestine, Kosovo and Taiwan (`world/countries.json`, built from Wikidata by `world/registry.py`).
| Layer | What it covers | How |
|---|---|---|
| 1. Structural (all pairs) | diplomatic relations, embassies and heads of mission, blocs, treaties, territorial claims, official language, WITS trade, UN DESA migration, project sanctions and special pairs | one query per state or for all states (`world/bulk.py`, ~1,200 requests instead of ~96,000), then the model's `build_states` / `derive_states` / `score` unchanged (`world/score_all.py`) |
| 2. Events (priority pairs) | news, leaders' actions, two-model classification, embassy absences, standing measures | `world/events_runner.py N` runs the next N pairs of `world/out/priority.json`; it stops by itself when providers run out of quota and resumes where it stopped |
```bash
cd engine/relations/world && python3 -I bulk.py && python3 -I score_all.py && python3 -I priority.py && python3 -I overlay_known.py && python3 -I events_runner.py merge && python3 -I export_app.py
```
`world/compare_known.py` checks the bulk path against the per-pair path (10 of 10 known pairs identical). The bulk cache (`world/world_cache.json`, ~18 MB) and `world/out/` are not committed: the first `bulk.py` run takes about 20 minutes.

**Read the structural layer for what it is.** Without the events layer R only reflects structure, so a war or a rupture that no data source records is invisible: Russia–Ukraine scores −13, Israel–Iran −9, Armenia–Azerbaijan +8 (Wikidata still lists the embassies). Pairs with no data-backed state (8,989) are shown grey, not neutral. Only 5 pairs have the events layer today. Wikidata timed out on the treaties of Brazil, Canada, Indonesia, the Netherlands and Norway; their treaties come from the other party's query, so only the 10 pairs among those five lack them.

## Running
Offline tests (no network, no LLM calls; they use the cached answers, `WGE_OFFLINE=1` stops the 1-day Wikidata/WITS cache from refreshing):
```bash
cd engine/relations/calibration && python3 -I test_reproduce.py
```
```bash
cd engine/relations/model && WGE_OFFLINE=1 python3 -I test_embassy.py
```
Score a pair (needs network and API keys; keys are read from a `.env.local` file, by default `~/Desktop/v0-equity-analysis-with-buffett/.env.local`, override with `WGE_ENV_PATH`):
```bash
cd engine/relations/model && python3 -I classify_score2.py ES-MA IN-CA --runs 2
```
Regenerate the spec: `cd engine/relations/model && python3 gen_doc.py`. Standard library only, tested on Python 3.14.5; macOS CA bundle at `/etc/ssl/cert.pem` is assumed in `providers.py`.

## Things to know before building on it
- **Frozen records:** `calibration/code_freeze.sha256` and the `*.sha256` files hash the files as they were in the prototype. Several scripts were edited here only to replace absolute paths with relative ones (`calib_lib.py`, `extract_hist.py`, `holdout2_run.py`, `holdout3_run.py`, `mag_env.py`), `providers.py` (key file via `WGE_ENV_PATH`), `gen_doc.py` and `classify_score2.py` (read/write `results/` and `docs/`), so those hashes will not match byte for byte.
- **Embassy state:** every run reports, per side, `PRESENT`, `ABSENT` or `UNKNOWN` with its source (`event`, `wikidata`, `web`, `none`) in the `embassies` field; only `ABSENT` is scored (−10 per side). A gap in Wikidata is never read as an absence: its coverage of ambassadors is very uneven (Spain has a current holder for 100 of 119 embassies, Canada for 4 of 99, Senegal for 0 of 27).
- **Runtime state is not included** (`model/quota_state.json`, provider cool-downs); it is created on first use and git-ignored.
- **Known limits** (listed in `docs/modelo_puntuacion.md` §8 and `docs/calibracion.md`, rounds 4-5): an absence whose return is missing from the facts and not confirmed by the web check stays at half weight (Morocco in ES-MA today), event decay while a measure is still in force, classifiers that almost never answer `NONE`, and a reset rule that only recognises diplomatic ruptures.
- Anchors and gold labels are the author's judgement on documented facts, not independent ground truth.
