# World Geopolitical Engine (Mundo)

Autonomous 3D/2D Spatial Intelligence & Macroeconomic Geopolitical Platform.

## Overview
This repository contains the standalone **World Geopolitical Engine** extracted from the equity analysis platform. It features:
- **3D Interactive Globe & 2D Mercator Projections**: Powered by Three.js / Globe.GL and D3.
- **Thematic Tactical Layers**:
  - `TIER-N`: Supply chain hard-country friction ($\ge 7.0$), OFAC sanctions, and upstream exposure.
  - `RECURSOS`: Critical commodities monopoly index, UNCTAD reserves, and diplomatic friendshoring substitution arcs.
  - `RUTAS`: 6 strategic maritime chokepoints (Hormuz, Malacca, Suez, Bab el-Mandeb, Panama, Bosporus) with JIT starvation simulation and COGS gross margin compression modeling.
  - `HUELLA`: Corporate facilities mapped to SEC Item 2 (Properties) with interactive tactical popovers and risk badges.
- **Ray Dalio Sovereign Power Radar & War Room**: 6-dimension sovereign strength index (Technology, Cabinet, Currency, Trade, Military, Stability) with wargame shock simulator and DEFCON levels.
- **Trade DAG Engine**: Directed Acyclic Graph modeling for intermediate pass-through nodes vs end nodes with pricing power, margin drain, and FCF capture.
- **HoI4 / EU4 Strategic Mechanics**: 8 corporate and 9 sovereign macroeconomic mechanics (Bankruptcy spiral, Retooling penalty, CapEx trap, Node attrition, Tall vs Wide, etc.).

## Getting Started

### Prerequisites
- Node.js >= 18
- npm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the Geopolitical Monitor.

### Typecheck & Tests
```bash
npm run typecheck
npm test
```

### Production Build
```bash
npm run build
```
